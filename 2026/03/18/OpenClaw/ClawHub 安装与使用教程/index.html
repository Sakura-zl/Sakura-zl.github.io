三、常见问题处理

问题：执行 clawhub search/explore/install 时出现 Rate limit exceeded 错误

原因说明

ClawHub 公共 API 对未登录用户有请求频率限制，短时间内多次请求会触发限流。

解决方案

方案 1：等待限流自动解除

限流通常会在 1-5 分钟内自动解除，等待片刻后重新执行命令即可。

方案 2：登录 ClawHub 账号获取更高配额
  1. 注册 ClawHub 账号：访问 https://clawhub.ai 完成注册
  2. 执行登录命令：

按照提示在浏览器中完成授权登录

登录后 API 请求配额会大幅提升，可避免频繁触发限流

方案 3：手动安装技能

如果限流长时间未解除，可通过 Git 手动克隆技能仓库到本地技能目录：

手动安装的技能会被 OpenClaw 自动加载，可正常使用，只是不会出现在 clawhub list 的结果中。

四、技能目录说明

OpenClaw 默认技能目录为：~/.openclaw/workspace/skills/

  • 所有安装的技能都会存储在该目录下

  • 手动添加的技能只要符合 AgentSkills 规范，会被自动识别和加载

  • 每个技能包含独立的 SKILL.md 配置文件和相关脚本资源
