向导会通过问答形式引导你完成基础配置：

  1. 安全提示：OpenClaw 拥有较高权限，输入 Yes 确认。

  2. 配置模式：选择 QuickStart（快速开始）即可。

  3. AI 模型提供商：

    • 如果有 API Key，选择对应服务商并按提示输入。

    • 如果没有，可以先选择 Skip for now 跳过，后续在 Web UI 中配置。

  4. 通信渠道：如飞书、Telegram 等，可以先跳过。

  5. 技能与 Hooks：推荐安装一些基础技能，或暂时跳过。

  6. 启动方式：选择 Hatch in TUI，进入终端交互界面。输入 Hello 若能正常回复，说明安装成功。按 Ctrl+C 退出 TUI。

注意：退出 TUI 后，OpenClaw 的 Gateway 服务会在后台继续运行。

第七步：后续管理与常用命令

作为 open 用户，你可以使用以下命令管理 OpenClaw：

命令 说明
openclaw status 查看服务状态
openclaw gateway restart 重启核心服务
openclaw gateway stop 停止核心服务
openclaw gateway start 启动核心服务
openclaw plugins list 列出已安装插件
openclaw plugins install <插件名> 安装插件（例如 @m1heng-clawd/feishu）
openclaw config set <key> <value> 修改配置
openclaw doctor 运行环境健康检查，排查问题
openclaw dashboard 生成 Web UI 访问链接
openclaw logs 查看运行日志
