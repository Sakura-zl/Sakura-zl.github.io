Ubuntu 版本 官方下载链接 (aka.ms 短链接)
Ubuntu 24.04 LTS https://aka.ms/wslubuntu2404 
Ubuntu 22.04 LTS https://aka.ms/wslubuntu2204 
Ubuntu 20.04 LTS https://aka.ms/wslubuntu2004 
Ubuntu 18.04 LTS https://aka.ms/wslubuntu1804
  1. 从微软官方链接下载 Ubuntu 22.04 的 .AppxBundle 包到 D 盘
  2. 将下载的文件重命名为 .zip 并解压到临时文件夹
  3. 根据系统架构 (x64/ARM64) 找到对应的 .appx 文件
  4. 再次解压该 .appx 文件以提取 install.tar.gz 到临时文件夹 D:\Ubuntu-temp
