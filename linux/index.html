Linux 工具集

这里收集了一些实用的 Linux 工具和软件。

系统管理

  • htop - 交互式进程查看器
  • nmon - 系统性能监控工具
  • ncdu - 磁盘使用情况分析器
  • rsync - 文件同步工具

开发工具

  • Vim/Neovim - 强大的文本编辑器
  • GCC/G++ - C/C++ 编译器
  • Python3 - Python 编程语言
  • Node.js - JavaScript 运行时环境

网络工具

  • curl - 命令行数据传输工具
  • wget - 网络下载工具
  • nmap - 网络扫描和安全审计工具
  • tcpdump - 网络数据包分析器

实用工具

  • tmux - 终端复用器
  • git - 版本控制系统
  • tree - 目录树显示工具
  • jq - JSON 处理工具

提示：大多数工具可以通过包管理器（apt、yum、pacman 等）安装。
