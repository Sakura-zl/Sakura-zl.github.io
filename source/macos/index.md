# macOS 工具集

这里收集了一些实用的 macOS 工具和软件。

## 系统工具

- **CleanMyMac X** - 系统清理和优化工具
- **The Unarchiver** - 解压缩工具
- **Alfred** - 生产力启动器
- **iStat Menus** - 系统监控工具

## 开发工具

- **Xcode** - Apple 官方开发工具
- **Homebrew** - 包管理器
- **iTerm2** - 终端替代品
- **Docker Desktop** - 容器化开发环境

## 设计工具

- **Sketch** - UI/UX 设计工具
- **Figma** - 协作设计平台
- **Affinity Designer** - 矢量图形设计
- **Pixelmator Pro** - 图像编辑工具

## 实用工具

- **Bartender** - 菜单栏管理
- **BetterTouchTool** - 输入设备增强
- **Amphetamine** - 防止系统休眠
- **HandBrake** - 视频转码工具

> 提示：许多工具可以通过 Homebrew 或 Mac App Store 安装。
